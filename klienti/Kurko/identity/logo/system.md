# KURKO / Logo na světlém pozadí

Pro nové návrhy používat [kurko-web-light.svg](kurko-web-light.svg): vektorové cesty z inline SVG v archivovaném HTML kurko.cz. Symbol je #447CBF, text je explicitně #000000 podle základního CSS `.logo {color:#000}`. Geometrie nebyla změněna; currentColor byl pro samostatný soubor pevně nastaven. Poměr viewBox je 210 : 67. Nejde o nově vymyšlený logotyp.

Pozadí bílé nebo světle šedé. Tmavé pozadí i tmavý panel pod logem jsou dle pokynu uživatele zakázané. Původní PNG kurko-01.png s bílým písmem zůstává nezměněné jako archivní podklad; nepoužívat jej jako důvod k tvorbě tmavé plochy.

Zachovat proporce a celé logo. Nepřidávat efekty, nenahrazovat název fontem. Pracovní ochranná zóna: čtvrtina výšky loga. Oficiální minimum ani konstrukční síť nejsou doložené. Při malém použití kontrolovat čitelnost slova REALITY.

Jednobarevná, samostatný symbol a čtvercová varianta nejsou dodané samostatně. Připravit podle konkrétní potřeby. Finální tisk vyžaduje kontrolu barevného profilu a exportu; existence SVG sama nepotvrzuje hotová tisková data.
